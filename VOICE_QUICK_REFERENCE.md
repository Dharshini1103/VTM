# 🎤 Voice Commands Quick Reference Card

## Basic Structure
```
[ACTION] task [TITLE] [MODIFIERS]
```

---

## Action Keywords
- **create** - Create new task
- **add** - Add new task  
- **new** - New task

---

## Priority Keywords
| Keyword | Level | Color |
|---------|-------|-------|
| urgent, asap, critical | URGENT | 🟣 Purple |
| high | HIGH | 🔴 Red |
| medium, normal, standard | MEDIUM | 🟠 Orange |
| low, minor | LOW | 🟢 Green |

**Default**: MEDIUM

---

## Deadline Keywords
| Phrase | Result |
|--------|--------|
| today | Today |
| tomorrow | Tomorrow |
| this week | Friday (EOW) |
| next week | +7 days |
| next month | +30 days |
| (none) | +7 days |

## Voice Input Steps

### 1️⃣ Click Voice Button
   Located in top-right corner → "Voice Input"

### 2️⃣ Wait for "Listening..."
   Microphone is ready

### 3️⃣ Speak Clearly
   "Create task review quarterly report high priority"

### 4️⃣ Review Modal
   Check extracted details

### 5️⃣ Confirm
   Click "Create Task" button

### 6️⃣ Done ✅
   Task appears with serial number in table

## Common Phrases

### For High Priority:
- "as urgent"
- "high priority"
- "asap"
- "critical"
- "important"

### For Deadline:
- "deadline today"
- "due tomorrow"  
- "this week"
- "next week"
- "by end of day"

### For Description:
Just continue speaking after the title!
```
"Create task meeting with team tomorrow to discuss Q1 roadmap"
```

---

## ✅ Do's
- ✅ Speak clearly at normal pace
- ✅ Use complete task titles
- ✅ Mention priorities explicitly
- ✅ Include date references
- ✅ Wait for "Listening..." indicator

---

## ❌ Don'ts
- ❌ Speak too fast or slow
- ❌ Use single-word titles
- ❌ Speak during "Processing..."
- ❌ Use special characters
- ❌ Forget action keyword (create/add/new)

---

## Troubleshooting

| Problem | Solution |
|---------|----------|
| No microphone detected | Check device settings |
| Microphone denied | Grant browser permission |
| No speech detected | Speak louder, clearer |
| Title not extracted | Use "Create task" + title |
| Browser doesn't support | Use Chrome/Edge/Safari |
